# LetsTalk – Next.js client (Phase 1: read flow)

Chats list, chat selection and messages with upward infinite scroll.
Stack: Next.js (App Router), React 19, TanStack Query, Zustand.

## Run

1. Start the backend (default `https://127.0.0.1:5000`, override with `LETSTALK_API_URL`, see `.env.example`).
2. `npm install && npm run dev` and open http://localhost:3000.
3. There is no login form. Log in via the Angular app, copy the token and run in this origin's browser console:
   `localStorage.setItem("auth-token", "<token>")`, then reload.

## Notes

- The browser talks to `/api/proxy/*`; the route handler forwards the `Authorization` header to the backend and accepts its self-signed certificate in development only.
- `src/lib/api/api-client.ts` is generated by NSwag (Fetch template) from `letstalk-api-fetch.nswag` in the repo root. Regenerate it with NSwagStudio; no copy step is needed.
- Messages: page 0 = latest messages, pages 1, 2, ... = older ones, loaded when scrolling up until an empty page is returned.
